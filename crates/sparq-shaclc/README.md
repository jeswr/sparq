# sparq-shaclc

SHACL Compact Syntax (1.2 + extended) parser for the sparq RDF engine —
**generated** from one [rdf-shuttle](https://github.com/jeswr/rdf-shuttle)
Shuttle grammar, emitting the same `oxrdf` shapes triples `sparq-shacl`
validates. Opt-in by construction: nothing in the workspace depends on this
crate, so core builds and bundles carry zero SCS code.

## 🚀 Quick start

```rust
use sparq_shaclc::{parse_strict, DEFAULT_BASE};

let doc = "PREFIX ex: <http://example.org/#>\nshape ex:S -> ex:C {\n}\n";
let (triples, outcome) = parse_strict(doc, DEFAULT_BASE)?;
assert_eq!(outcome.prefixes.len(), 6); // 5 predeclared + ex
# Ok::<(), sparq_shaclc::ShaclcError>(())
```

`parse(text, base, Profile::Strict | Profile::Extended)` picks the parser;
`raw::shaclc12` / `raw::shaclc12ext` expose the generated streaming + chunked
push APIs on their zero-dependency term model.

## ✨ What's inside

- **Strict** (`Profile::Strict`): the W3C CG SHACL-CS surface **plus the
  RDF 1.2 layer** (triple terms in value positions, directional language
  tags, `TripleTerm` nodeKind, `reifierShape`/`reificationRequired`).
  The four shaclc-js extensions are *absent from its parse tables*, so
  strict mode provably rejects them — fixing shaclc-js's strict-mode
  enforcement leak by construction.
- **Extended** (`Profile::Extended`): strict plus the shaclc-js extensions
  (node-shape annotation lists, `% … %` property escapes, trailing Turtle
  statements, the `a` keyword).
- **Checked-in artifacts, no build-time codegen**: `src/raw/*.rs` are
  generated by rdf-shuttle's `gen-rs` backend (provenance pinned in
  `src/provenance.rs`; regenerate with `scripts/regen-shuttle-parsers.sh`).
  `tests/provenance_drift.rs` fails if the vendored grammar drifts from the
  recorded pin — no Node in the build graph or the test loop.
- **Tested three ways**: the vendored shaclc-js/rdf12 corpus against an
  independent `oxttl` oracle (graph isomorphism); a differential against
  `sparq-shacl`'s hand-rolled `scs` parser on every fixture both accept
  (divergences are root-caused, beaded, and pinned so the list can only
  shrink); and push-vs-one-shot chunking invariance.
- **Parse-only today**: the print direction (serializer with the
  residual-based "not compact-expressible" verdict) lands when rdf-shuttle
  `gen-rs` grows the residual-consumption printer its `gen-js` backend
  already derives.
