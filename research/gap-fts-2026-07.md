## 2. Canonical protocol (design record §4)

1. Dedicated quiet EC2 box (tag `sparq-bench`, orphan-proof self-terminate), one engine
   active at a time, SAME corpus + SAME pinned 200-pair query set, best-of-N:

   ```sh
   CANONICAL=1 OUT_DIR=bench/canonical-competitor-results/<date>/ \
     TIMEOUT_S=900 scripts/bench/fts-same-box.sh          # latency axis (both engines)
   ```

2. **Oracle before stopwatch (INVARIANT):** per-workload hit counts are cross-checked
   engine-vs-engine (`count_crosscheck` in the envelope) and recorded **as returned**;
   a disagreement disqualifies that workload's comparative timing (`agree:false`) and
   is a recorded finding — never adjusted, never rerun-until-it-matches. The sparq side
   additionally rides the committed `bench/fts/expected.tsv` hard gate at the pinned
   corpus.

3. IR-quality axis (BEIR, gather-only — corpus not redistributable in-repo):

   ```sh
   cargo build -p sparq-text --release --example beir_text
   BEIR_CUT=scifact SPARQ_TEXT_BEIR=target/release/examples/beir_text \
     scripts/gather-competitors.sh --run --only lucene-anserini
   ```

   Both engines are scored by the one shared scorer against the same qrels; deficits
   (`1 - Recall@100`, `1 - nDCG@10`) land in the git-ignored gather results file, then
   here with provenance.

4. Envelopes carry `canonical:true`, instance/commit/UTC provenance, statuses, and the
   crosscheck. A failed/absent competitor is a missing column + a re-run action, never
   a sparq win.
