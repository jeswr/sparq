# sparq-terse Phase-5 A/B harness

> 🤖 **SPARQ agent** [OPUS-4.8] — the **adoption gate** for the `sparq-terse`
> LLM-ergonomic SPARQL surface (bead `sq-bzign`, epic `sq-2m6zm`, design
> `research/llm-ergonomic-sparql-surface.md` §5/§8.6). A pre-registered, falsifiable
> A/B that measures whether authoring a PKG query in the terse dialect saves
> cache-discounted effective tokens **at no loss of correctness**, and emits a §5.5
> verdict object PER LEVER. Non-sycophantic: a lever that does not clear the frozen bar
> is reported as not-adopted.

## 🚀 Run it

```bash
bench/terse/run.sh                       # input-authoring-proxy fidelity (this env)
bench/terse/run.sh --transcripts <dir>   # full-session fidelity, if a tagged fan-out exists
```

Needs only `cargo` + stdlib `python3`. It builds `sparq-cli` + the `terse-expand` /
`legend-card` examples, generates the real per-arm context cards, grades every arm's
reference query through the real transpiler + engine, accounts the effective tokens,
and writes `verdict.json`. **Every number it prints is runtime-only / NON-CANONICAL**
(work-box; never frozen into committed markdown — `scripts/check-no-perf-numbers.py`).

## ✨ What is committed (vs regenerated)

| Committed (the protocol) | Regenerated by `run.sh` (git-ignored) |
|---|---|
| `PREREG.md` — frozen hypotheses, arms, metric, bar, kill-criteria | `grades.json`, `tokens.json`, `verdict.json` |
| `tasks/terse_tasks.json` — the 30 frozen stratified tasks + gold SPARQL | `schema-card.txt`, `legend-card.txt` (the per-arm cards) |
| `tasks/reference_queries.json` — the per-arm reference query | |
| `grade.py` / `tokens.py` / `verdict.py` / `make_schema_card.py` / `run.sh` | |
| `RESULTS.md` — the measurement record (bench/ is the sanctioned home for figures) | |

The two real binaries the harness leans on ship in the crate, not here:
`cargo run -p sparq-terse --features vectors --example terse-expand` (the deterministic
transpile-and-echo tool) and `--example legend-card` (the frozen legend card verbatim).

## 📚 The three arms + the levers they test

- **A — plain SPARQL** (baseline): schema card + `PREFIX`/prefixed names.
- **B — terse keyword** (lever 1): `legend_card()` + `K:<name>`.
- **C — terse + `V()`** (lever 3): as B + `V("phrase")` lexical-first resolution.

The verdict (`verdict.py`) decides each lever on its OBJECT — `token_win`
(≥20% paired-median reduction, Wilcoxon p<0.05, bootstrap CI excludes 0, survives the
cache discount) **AND** quality non-regression (`parses`/`grounded`/F1 ≥ A; for V,
`resolution_correctness == 1.0`). See `PREREG.md` for the frozen rule and `RESULTS.md`
for the latest measured outcome and the honest findings.
