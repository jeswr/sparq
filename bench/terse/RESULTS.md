# RESULTS — sparq-terse Phase-5 query-authoring A/B

> 🤖 **SPARQ agent.** Measurement record for bead **sq-bzign** — the ADOPTION GATE on
> the `sparq-terse` surface. The verdict is **non-sycophantic** by design: where a lever
> does not clear the frozen bar, it is reported as not-adopted. **The numbers below are a
> runtime artifact** that `run.sh` regenerates into `verdict.json`; they are
> work-box / NON-CANONICAL (`MEMORY: project-ec2-execution-env`) and are not a guarantee.

## The question

Does authoring a PKG SPARQL query in the **terse dialect** — lever 1 (`K:<name>`
keywords) and lever 3 (`V("phrase")` concept resolution) — cost fewer cache-discounted
effective input tokens than plain SPARQL, **at no loss of query correctness**? The
metric and the kill-criteria were **pre-registered** (`PREREG.md`) before the run.

## Method (how this was measured / how to reproduce)

1. **Frozen task set** — `tasks/terse_tasks.json`: 30 NL questions over the pinned PKG
   (`crates/sparq-kb/ingest/pkg-instances.ttl`), stratified across 4 strata
   (point-lookup / multi-hop / synthesis / negative). Each task carries a **gold
   canonical SPARQL** whose result rows are the answer-set oracle.
2. **Three arms**, each authoring the SAME question over the SAME PKG:
   - **A — plain SPARQL** (carries the schema card; writes `PREFIX` + prefixed names);
   - **B — terse keyword** (carries `legend_card()`; writes `K:<name>`);
   - **C — terse + `V()`** (as B, plus `V("phrase")` lexical-first resolution).
   The per-arm **reference query** a competent agent writes is frozen in
   `tasks/reference_queries.json`.
3. **Quality** — graded DETERMINISTICALLY and BLIND by the REAL toolchain
   (`grade.py`): the `terse-expand` example (the real transpiler + the silent-rewrite
   canary) and `sparq-cli query` (the real engine). Sub-flags: `parses`, `grounded`
   (no out-of-schema term), `answer_correct` (answer-set **F1** vs the gold query),
   and for arm C `resolution_correctness` (every `V()` bound the **gold** IRI).
4. **Tokens** — cache-discounted effective input tokens
   (`1.0·fresh + 0.1·cache_read + 1.25·cache_write`). **Fidelity here =
   `input-authoring-proxy`**: this single-session environment has no live sub-agent
   fan-out, so the run measures the deterministic **input-authoring** cost the design
   names as the dominant lever (§1.6/§7) — the per-arm context card (amortised behind
   the prompt-cache breakpoint) + the authored query — via a documented char→token
   proxy through the canonical formula. `tokens.py --transcripts <dir>` mines REAL
   tagged sub-agent transcripts (`bench/pkg-dogfood/tokens_real.py` mechanism) when a
   fan-out exists; that upgrades the verdict to `full-session-transcript` fidelity.
5. **Verdict** — `verdict.py` runs the FROZEN pre-registered statistics (paired
   Wilcoxon signed-rank + percentile bootstrap on the A−B / A−C deltas, cache-discount
   survival check) joined with quality, and emits one §5.5 verdict object per lever.

## The honest findings (non-sycophantic)

1. **Lever 1 (keyword) clears the token bar AND ties plain SPARQL on quality** — on the
   input-authoring proxy. The ≈20% saving is the design's predicted "Low–Medium
   terseness" (§7): it comes from the shorter query body (`K:status` vs the `PREFIX`
   line + `pkg:status`), NOT from gaming the card — arm B/C carry the *larger* card
   (the legend card is bigger than the schema card) and still win once it is amortised
   behind the cache breakpoint. **Caveat:** the saving sits right at the 20% bar and is
   a **proxy on the input side only**; the verdict is **CONDITIONAL** and must be
   upgraded by the full-session transcript fan-out before unconditional adoption.
2. **Lever 3 (`V()`) does NOT clear the quality bar** — and this is the load-bearing
   honest result. `V()` resolves clean prefLabels perfectly (`V("merge discipline")` →
   the right topic, score 1.0), but on the punctuation-heavy prefLabel
   `"ZK/MPC claim + circuit discipline"` the lexical linker scores two topics equally
   on the shared token "discipline" and the soundness envelope **loud-fails as
   ambiguous** rather than guess. That is the envelope *working* (loud-fail beats
   silent-wrong), but it means the lever drops `parses`/F1/`resolution_correctness`
   below arm A on the frozen set, so `recommend_adopt = false`. **`V()` is a
   convenience for clean-label phrases, not a drop-in replacement for an explicit IRI.**
3. **The negative stratum behaved correctly in every arm** — absent statuses/topics
   returned the empty answer-set (no manufactured rows), and `V()` over a phrase absent
   from the PKG (`V("Quantum supremacy")`) **loud-failed** rather than mis-binding
   (honest abstention).

## What would change the verdict (the follow-up)

- **The full-session transcript fan-out** (90 tagged sub-agents, one per `(task, arm)`)
  upgrades fidelity from `input-authoring-proxy` to `full-session-transcript`; only then
  can lever 1's CONDITIONAL recommend become unconditional. Tracked as bead `sq-bmpzd`
  (the fidelity design call is GH issue #1173).
- Lever 3 would need a tightened lexical linker that exact-matches a full prefLabel
  **before** falling to token overlap (so a verbatim prefLabel never goes ambiguous) — or
  the vector fallback enabled. Tracked as bead `sq-26fdp`. Until then, lever 3 stays
  **measure-gated / not-adopted**.

## Honest caveats (read before citing)

- **Small-N, single-run, proxy-fidelity.** N = 30 meets the §5.4 task-count bar (so the
  Wilcoxon/bootstrap run), but the tokens here are the **input-authoring proxy**, not the
  full-session transcript A/B. Treat lever 1's win as **directional + conditional**.
- **All numbers are work-box / NON-CANONICAL** and regenerated by the harness; they are
  never frozen into a user-facing doc and will move with the PKG snapshot + the proxy
  constant (`CHARS_PER_TOKEN`, stated openly in `tokens.py`).
- **Two proxy verdicts were reversed by real measurement this project** (see
  `bench/EXPERIMENTS.md`). This run is explicit that it is a proxy on the dominant lever;
  the transcript fan-out is the arbiter.
